# 个人主页（GitHub Pages 单文件版）

一个**零依赖、纯原生 HTML/CSS/JS** 的个人博客主页，只有 `index.html`（页面）和 `posts.json`（文章数据）两个文件，无需任何构建工具，上传到 GitHub 即可上线。博客页面为**纯只读**：文章由你自己写进 `posts.json` 后提交，访客只能阅读。

## ✨ 功能特性

- 单文件结构：所有样式（CSS）与脚本（JS）均内联，没有外部 CDN 依赖，完全离线可用
- 响应式设计：完美适配手机 / 平板 / 桌面端
- 深色 / 浅色主题切换，并记住你的选择（localStorage）
- 首屏打字机效果、滚动显现动画
- 项目技术栈筛选：点击标签按钮即时过滤项目，支持多选，并可自由切换并集 / 交集组合方式；按钮根据项目卡片的 `data-tags` 自动生成
- 滚动时导航栏高亮当前区块、毛玻璃导航栏
- 一键复制邮箱、返回顶部按钮、移动端汉堡菜单
- 博客纯只读：文章存在仓库的 `posts.json` 里，页面只负责渲染和阅读（Markdown 正文、点击卡片弹出全文阅读），**没有任何编辑入口**，访客无法修改
- 板块：首页 Hero / 项目（含技术栈筛选）/ 博客 / 联系我
- 内置示例内容，所有需要修改的地方都有 `✏️` 注释标记

## 🚀 本地预览

直接双击 `index.html` 用浏览器打开即可。也可以起一个本地服务器：

```bash
# 在该目录下（任选其一）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🌐 部署到 GitHub Pages

1. **创建仓库**：在 GitHub 新建一个仓库。如果仓库名叫 `用户名.github.io`，网站地址就是 `https://用户名.github.io`；如果是其他仓库名，地址为 `https://用户名.github.io/仓库名`。
2. **上传文件**：把 `index.html` 上传到仓库**根目录**（或 `docs/` 目录）。
3. **开启 Pages**：进入仓库 `Settings` → `Pages` → `Source` 选择 `Deploy from a branch` → 分支选 `main` → 文件夹选 `/ (root)`（文件在 `docs/` 则选 `/docs`）→ `Save`。
4. **等待生效**：约 1–2 分钟后访问上面生成的网址即可。
5. **（可选，推荐）**：在根目录放一个空的 `.nojekyll` 文件，跳过 Jekyll 处理，避免个别文件被误处理。
6. **（可选）**：在 Pages 设置中绑定你自己的自定义域名。

## ✏️ 自定义指南

打开 `index.html`，按下面的清单搜索替换即可（大部分位置都有 `✏️` 注释）：

| 要改的内容 | 怎么改 |
| --- | --- |
| 姓名 | 搜索「你的名字」全部替换 |
| 邮箱 | 搜索「hello@example.com」（HTML 按钮文字和底部 `<script>` 里的 `email` 变量，共两处） |
| 打字机角色 | 底部 `<script>` 中 `roles` 数组 |
| 头像 / 照片 | 搜索「把这里的占位图标替换成你的照片」，按注释换成 `<img>` |
| 社交链接 | 搜索「https://github.com/你的用户名」，替换为你的链接；不需要的图标整块删除 |
| 项目 | 每张卡片的 `data-tags` 属性即其技术栈（英文逗号分隔）；新增项目 = 复制一个 `<article>` 块 |
| 技术栈筛选 | 无需手动维护：按钮根据项目卡片的 `data-tags` 自动生成；支持多选，选中 ≥2 个标签时可切换「并集 / 交集」，点「全部」清空选择 |
| 文章 | 存放在仓库的 `posts.json` 中；新增文章 = 在数组里加一个对象并提交（页面无编辑入口） |
| 主题色 | `<style>` 顶部的 CSS 变量 `--accent`、`--accent-2`、`--accent-3` |

## 🆕 如何新增一个项目

1. 复制一个 `.project-card` 的 `<article>` 块；
2. 修改 `data-tags` 属性（技术栈，英文逗号分隔——顶部筛选按钮和卡片上的标签会自动出现）；
3. 修改图标、标题、描述，以及「演示 / 源码」链接。

## ✍️ 如何写文章并上传

页面**只负责展示，没有任何编辑入口**——文章内容全部由你自己写好后提交到仓库。

### 方式一：GitHub 网页上直接改（最省事）

1. 打开仓库里的 `posts.json` → 点右上角铅笔图标 **Edit**；
2. 在数组里加一个对象（格式见下）→ 拉到页面下方点 **Commit changes**；
3. 约 1 分钟后刷新博客页面，新文章就出现了。

### 方式二：本地编辑后 push

1. 在本地修改 `posts.json`（或用任意编辑器 / 脚本生成）；
2. `git add posts.json && git commit -m "新增文章" && git push`；
3. 同样约 1 分钟后生效。

### 文章字段说明

`posts.json` 是一个数组，每篇文章一个对象：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识（随便一串英文/数字，不能重复），用于文章链接 `#post-<id>` |
| `title` | 标题 |
| `date` | 日期，建议 `YYYY-MM-DD`（列表按它倒序排列） |
| `category` | 分类标签，显示在卡片上 |
| `excerpt` | 摘要，显示在卡片上 |
| `content` | 正文，Markdown 格式 |

正文支持：`#` 标题、`-` / `1.` 列表、`> 引用`、`**加粗**`、`*斜体*`、行内 `代码`、三反引号代码块、`[文字](链接)`、`![说明](图片地址)`、`---` 分隔线。

```json
[
  {
    "id": "hello-world",
    "title": "我的第一篇文章",
    "date": "2026-01-01",
    "category": "随笔",
    "excerpt": "卡片上显示的一句话摘要。",
    "content": "## 小标题\n\n正文支持 **加粗**、[链接](https://example.com) 和代码块。\n\n- 列表项一\n- 列表项二\n\n> 引用一段话。"
  }
]
```

> 注意：JSON 里的换行必须写成 `\n`，双引号要转义成 `\"`。改完可用在线 JSON 校验工具检查格式，避免页面读不出来。

### 读不到文章会怎样？

如果 `posts.json` 不存在或格式错误，页面会自动回退显示内置的示例文章，不会白屏。

## ❓ 常见问题

- **访客能改我的文章吗？** 不能。页面没有任何编辑入口，文章内容存在你自己的仓库里，只有能 push 这个仓库的人才能改。
- **提交后访客看不到新文章？** GitHub 有缓存，等 1–2 分钟并强制刷新（Ctrl + F5）即可。
- **文章顺序怎么定？** 按 `date` 字段倒序排列，日期新的在前。
- **本地正常，线上空白或乱版？** 检查文件名是否为 `index.html`、路径大小写是否一致、Pages 的 Source 文件夹是否选对。
- **改了颜色想换回来？** 直接还原 `<style>` 顶部的 CSS 变量即可，默认是靛蓝 → 紫 → 青渐变。
- **浏览器顶部地址栏颜色？** 由 `<meta name="theme-color">` 控制，与主题色一起改。
